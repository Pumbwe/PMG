MA110 – Mathematical Methods
Foundational Notes for University Students

Course Overview
MA110 builds essential mathematical skills: sets, algebra review, functions, coordinate geometry, trigonometry, sequences, matrices, and basic calculus ideas. Used in engineering, sciences, and related fields.

1. Introductory Set Theory

  • Set: Collection of distinct objects (elements/members)
  • Notation:
    • Roster: A = {2, 4, 6, 8}
    • Set-builder: B = {x | x is even positive integer ≤ 10}
  • Empty set: ∅ or { }
  • Universal set: U (usually the context)
  • Subset: A ⊆ B
  • Operations:
    • Union: A ∪ B
    • Intersection: A ∩ B
    • Difference: A \ B or A – B
    • Complement: A′ or Aᶜ
Venn Diagram Tip: Practice shading A ∪ (B ∩ C)', etc.

2. Preliminary Algebra & Inequalities

  • Indices / Exponents: a^m × a^n = a^(m+n), (a^m)^n = a^(mn)
  • Surds: √(a×b) = √a × √b, rationalize denominators
  • Quadratic equations: ax² + bx + c = 0 → x = [-b ± √(b²-4ac)] / 2a
  • Quadratic inequalities: Solve =0 first, then use sign table / number line
Example: Solve x² – 5x + 6 > 0
Roots: x=2, x=3 → solution: x < 2 or x > 3

3. Functions & Graphs

  • Definition: Relation where each x has exactly one y → y = f(x)
  • Domain, Codomain, Range
  • Types:
    • Linear: f(x) = mx + c
    • Quadratic: f(x) = ax² + bx + c
    • Polynomial, Rational, Exponential, Logarithmic
  • One-to-one (injective), Onto (surjective), Bijective
  • Inverse function: f⁻¹(x) exists if one-to-one
  • Composition: (f ∘ g)(x) = f(g(x))

4. Sequences & Series

  • Arithmetic sequence: a, a+d, a+2d, …
    nth term: aₙ = a + (n-1)d
    Sum: Sₙ = n/2 [2a + (n-1)d] or n/2 (a + l)
  • Geometric sequence: a, ar, ar², …
    nth term: aₙ = ar^(n-1)
    Sum (finite): Sₙ = a(1-r^n)/(1-r) (r ≠ 1)

5. Coordinate Geometry

  • Distance: √[(x₂-x₁)² + (y₂-y₁)²]
  • Midpoint: ((x₁+x₂)/2, (y₁+y₂)/2)
  • Gradient / Slope: m = (y₂-y₁)/(x₂-x₁)
  • Equation of line:
    • y = mx + c
    • y – y₁ = m(x – x₁)
  • Parallel lines: m₁ = m₂
  • Perpendicular: m₁ × m₂ = -1

6. Matrices & Determinants (Basic)

  • Order: rows × columns
  • Addition & scalar multiplication
  • Matrix multiplication: row × column
  • Determinant (2×2): | a b | = ad – bc
    | c d |
  • Inverse (2×2): (1/det) × | d -b |
