Introduction to Organic Chemistry

Lecture notes: atomic theory, electrons & orbitals, shells, subshells, and electron configuration.

What is an atom?

An atom is the smallest unit of matter that retains the chemical properties of an element. Atoms are made of three main subatomic particles: protons, neutrons, and electrons. Protons and neutrons form the nucleus, while electrons occupy regions around the nucleus.

Figure: schematic: nucleus (protons & neutrons) and electron shells (K, L, ...).

Key points

  • Protons carry positive charge; electrons carry negative charge.
  • In a neutral atom, number of protons = number of electrons.
  • Neutrons are neutral and contribute to mass but not charge.

Atomic number and mass number

Atomic number (Z) = number of protons in the nucleus. All atoms of an element share the same Z.

Mass number (A) = total number of protons + neutrons.

Calculate subatomic particles

Given atomic number and mass number:

  • Number of protons = atomic number (Z)
  • Number of electrons = atomic number (Z) (for neutral atoms)
  • Number of neutrons = mass number (A) − atomic number (Z)
Example
The atomic number of sodium is 11 and its mass number is 23.
  • Protons = 11
  • Electrons = 11
  • Neutrons = 23 − 11 = 12

Electrons and orbitals

Electrons determine chemical bonding and reactivity. They exhibit wave–particle duality. Orbitals are mathematical functions (from quantum mechanics) that describe regions of high probability where electrons are found.

Important orbital types

  • s orbital — spherical (one orbital per s subshell)
  • p orbitals — dumbbell-shaped (three orbitals per p subshell)
  • d and f — more complex shapes (five and seven orbitals respectively)

Quantum numbers (brief)

  • n — principal quantum number (shell)
  • l — angular momentum quantum number (subshell: s=0, p=1, d=2, f=3)
  • ml — magnetic quantum number (orbital within subshell)
  • ms — spin quantum number (±½)

Shells, subshells and orbitals

Shell (n) — energy level (K, L, M, ...). Each shell contains subshells. Subshell (s, p, d, f) — set of orbitals with same l value. Orbital — region that can hold up to 2 electrons.

Electron configuration

Electron configuration describes how electrons occupy orbitals. Example for carbon: 

C: 1s² 2s² 2p²  (or [He] 2s² 2p²)

Remember: electrons fill orbitals following the Aufbau principle, Hund's rule, and the Pauli exclusion principle.

Valence electrons

Valence electrons are the outermost electrons involved in bonding. For carbon, valence electrons = 4 (2s² 2p²), so valency = 4.

Practice questions

Question 1
The atomic number of sodium is 11 and its mass number is 23. Calculate the number of protons, neutrons and electrons.
Answer
  • Protons = 11
  • Electrons = 11
  • Neutrons = 23 − 11 = 12
Question 2
Write the electron configuration for magnesium (atomic number 12).
Answer

Mg: 1s² 2s² 2p⁶ 3s² (or [Ne] 3s²)
