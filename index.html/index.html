How to add content

Add program folders at the repository root. Each program folder should follow this skeleton: 

Program_Name/
  index.html
  meta.json (optional)
  notes/
    index.html
    topic-1.html
    topic-2.html
  past-papers/
    index.html
    ch260-2019.html
  assignments/
    index.html
    assignment-01.html
  lab-reports/
    index.html
    template.html

Use lowercase, hyphens, and no leading/trailing spaces in filenames and folders. The portal counts items by fetching each section's index.html and counting <li> entries.
